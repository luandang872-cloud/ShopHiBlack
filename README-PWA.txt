HÍ BLACK SHOP - PWA

Đã thêm:
- manifest.webmanifest
- service worker (offline cache)
- icon 192x192 và 512x512
- iPhone/PWA metadata

Cách dùng:
1. Deploy toàn bộ thư mục lên Netlify.
2. Mở link website bằng Safari trên iPhone.
3. Bấm nút Chia sẻ -> Thêm vào Màn hình chính.
4. Mở icon Hí Black như một app.

Lưu ý: PWA cần chạy qua HTTPS (Netlify đáp ứng điều này).
